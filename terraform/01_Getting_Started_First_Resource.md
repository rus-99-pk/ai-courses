# Тема 1: Установка и первый ресурс

## Какую проблему мы решаем?

Мы хотим начать работать с Terraform, но у нас ничего не установлено. Наша цель — убедиться, что всё работает, создав самый простой возможный ресурс без необходимости настраивать облачные аккаунты.

### Задача: Создать локальный текстовый файл с помощью Terraform.

Это идеальный первый шаг, так как он не требует ключей доступа к облакам и показывает основной рабочий процесс.

## Шаг 1: Установка Terraform

Terraform — это один бинарный файл.
1.  Перейдите на [официальную страницу загрузки Terraform](https://www.terraform.io/downloads.html).
2.  Скачайте архив для вашей операционной системы.
3.  Распакуйте его и поместите исполняемый файл `terraform` в директорию, которая находится в вашем системном `PATH` (например, `/usr/local/bin` в Linux/macOS или добавьте путь в переменные среды в Windows).
4.  Проверьте установку, выполнив в терминале:

```bash
terraform --version
```
Вы должны увидеть версию Terraform.

## Шаг 2: Основной рабочий цикл Terraform

Рабочий цикл Terraform состоит из трёх основных команд. Запомните их, это 90% вашей работы с Terraform.

1.  `terraform init` — **Инициализация**. Скачивает необходимые плагины (провайдеры) и подготавливает рабочую директорию. Выполняется один раз в начале проекта.
2.  `terraform plan` — **Планирование**. Terraform анализирует ваш код, сравнивает его с текущим состоянием и показывает, что будет создано, изменено или удалено. **Ничего не меняет.**
3.  `terraform apply` — **Применение**. Выполняет план, созданный на предыдущем шаге, и вносит реальные изменения в инфраструктуру.

## Шаг 3: Создаем наш первый ресурс

1.  Создайте новую директорию для проекта, например `terraform-hello-world`, и перейдите в неё.
2.  Создайте файл с именем `main.tf`. Все файлы с расширением `.tf` Terraform читает автоматически.
3.  Добавьте в `main.tf` следующий код:

```hcl
# main.tf

# Мы сообщаем Terraform, что будем использовать провайдер "local".
# Провайдер — это плагин для управления определенным типом ресурсов.
terraform {
  required_providers {
    local = {
      source  = "hashicorp/local"
      version = "2.2.3"
    }
  }
}

# Мы описываем ресурс, который хотим создать.
# "local_file" — это тип ресурса (локальный файл).
# "hello" — это имя этого ресурса внутри нашего Terraform-кода.
resource "local_file" "hello" {
  # Аргументы ресурса:
  content  = "Hello, Infrastructure as Code!" # Содержимое файла
  filename = "${path.module}/hello.txt"       # Путь и имя файла
}
```

## Шаг 4: Выполняем команды

Теперь выполните в терминале в этой же директории:

### Команда-методичка

1.  **Инициализация**:
    ```bash
    terraform init
    ```
    *Ожидаемый результат*: Terraform скажет, что инициализировал бэкенд и плагины. В директории появится папка `.terraform`.

2.  **Планирование**:
    ```bash
    terraform plan
    ```
    *Ожидаемый результат*: Terraform покажет план. Вы увидите зеленый `+` и описание ресурса `local_file.hello`, который будет создан. В конце будет строка `Plan: 1 to add, 0 to change, 0 to destroy.`

3.  **Применение**:
    ```bash
    terraform apply
    ```
    *Ожидаемый результат*: Terraform снова покажет план и спросит вашего подтверждения. Введите `yes` и нажмите Enter. После выполнения вы увидите `Apply complete! Resources: 1 added, 0 changed, 0 destroyed.`

**Проверка**: В вашей директории появился файл `hello.txt` с текстом "Hello, Infrastructure as Code!". Также появился файл `terraform.tfstate`, который хранит состояние вашей инфраструктуры. **Никогда не редактируйте этот файл вручную!**

## Шаг 5: Уничтожение ресурса

Чтобы удалить все ресурсы, описанные в коде, используется команда `destroy`.

```bash
terraform destroy
```
Введите `yes` для подтверждения. Файл `hello.txt` будет удален.

**Поздравляем!** Вы только что прошли полный цикл управления инфраструктурой с помощью Terraform.
