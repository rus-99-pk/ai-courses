# Курс: Infrastructure as Code с Terraform

Добро пожаловать в курс по Terraform! Здесь вы пройдете путь от новичка до уверенного пользователя, способного автоматизировать управление инфраструктурой.

**Цель курса:** Научить вас принципам Infrastructure as Code (IaC) и дать практические навыки работы с Terraform для декларативного описания и развертывания инфраструктуры в любом облаке.
