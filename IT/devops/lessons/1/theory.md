*   **Урок 1: Системы Контроля Версий и Автоматизация Сборки**
    *   **Цель:** Понять жизненный цикл ПО в DevOps, освоить продвинутые возможности Git для командной работы, настроить базовую автоматизацию сборки.
    *   **Ключевые Темы:**
        *   Жизненный цикл ПО в классике и DevOps.
        *   Проблематика "функциональных колодцев".
        *   Основы бережливого производства (Lean) и их применение в IT.
        *   Git: повторение основ, ветвление (Branching), слияние (Merging), rebase.
        *   Git Workflow: Feature Branch Workflow, GitFlow (обзор).
        *   Gitea (или аналог типа GitLab/GitHub): Установка, настройка репозиториев, пользователей, работа с Pull/Merge Requests.
        *   Maven: Жизненный цикл сборки (clean, compile, test, package, install, deploy), POM файл, зависимости.
        *   Введение в Jenkins: Установка, интерфейс, понятия Job, Freestyle Job.
    *   **Практические Задачи (Hands-on Labs):**
        1.  **Git Practice:** Создать репозиторий, поработать с ветками (создать Feature Branch, сделать коммиты, слить с develop, сделать rebase), разрешить конфликты слияния.
        2.  **Gitea Setup:** Развернуть Gitea (локально или на VM). Создать организацию/группу и репозиторий для нашего тестового приложения. Добавить туда код приложения.
        3.  **Maven Practice:** Использовать/создать простой Maven проект (например, Hello World REST API на Spring Boot). Понять структуру проекта. Запустить различные фазы сборки из командной строки (`mvn clean package`).
        4.  **Jenkins Basic Setup:** Развернуть Jenkins. Установить необходимые плагины (например, Git, Maven Integration).
        5.  **Automated Build Job:** Создать Jenkins Freestyle Job, который:
            *   Клонирует код вашего приложения из Gitea.
            *   Запускает сборку Maven (`mvn clean package`).
            *   Проверяет результат сборки (успех/неудача).
            *   Настроить триггер сборки по изменению в репозитории (Webhook из Gitea).
    *   **Результат:** Работающий пайплайн (пока в виде простого Job), который автоматически собирает приложение при коммите в Git, и понимание основ командной работы с Git и централизованным репозиторием.
