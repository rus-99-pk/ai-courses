*   **Урок 3: Сети и Основы Работы на Серверах Linux**
    *   **Цель:** Углубить знания Linux и сетей, необходимые для работы с серверами и деплоя приложений.
    *   **Ключевые Темы:**
        *   Основы работы с Linux: Командная строка (продвинутые команды), управление файлами и директориями, поиск файлов (find, grep).
        *   Пользователи и права доступа (chmod, chown, su, sudo).
        *   Управление процессами (ps, top, htop, kill), сервисами (systemctl, service).
        *   Фоновые задачи (nohup, screen, tmux).
        *   Дисковая система: Партиционирование (fdisk, parted), Файловые системы (ext4, XFS), Монтирование.
        *   Logical Volume Management (LVM): Создание PV, VG, LV, расширение/уменьшение LV.
        *   Основы сетей: IP-адресация (IPv4/IPv6), Маски подсети, Шлюз по умолчанию.
        *   Протоколы: TCP/IP, HTTP/HTTPS.
        *   Сетевые утилиты: ping, traceroute, netstat, ss, tcpdump, curl, wget.
        *   Файрволы: iptables / firewalld (базовые правила).
        *   SSH: Ключи, аутентификация, туннелирование (опционально).
        *   Введение в виртуализацию: Гипервизоры (Type 1 vs Type 2), Виртуальные машины, Виртуальные сети.
    *   **Практические Задачи (Hands-on Labs):**
        1.  **Linux CLI Mastery:** Развернуть чистую VM с Linux. Выполнить серию задач: найти файлы по шаблону, изменить права доступа, создать пользователя и выдать ему sudo без пароля, запустить процесс в фоне, проанализировать загрузку CPU/RAM.
        2.  **Disk Management:** Добавить виртуальный диск к VM. Разметить его, создать LVM группу и логический том. Отформатировать его и примонтировать. Потренироваться в расширении LV.
        3.  **Networking Practice:** Проанализировать сетевые интерфейсы VM. Попробовать настроить статический IP-адрес. Использовать сетевые утилиты для диагностики. Настроить базовые правила файрвола (например, разрешить только SSH и HTTP).
        4.  **SSH Keys:** Настроить беспарольный вход по SSH с вашей рабочей машины на VM.
        5.  **Deploy Application Manually:** Используя полученные знания, вручную "развернуть" ваше приложение на VM (скопировать артефакт, установить зависимости, запустить сервис). Это поможет понять, что именно мы будем автоматизировать дальше.
    *   **Результат:** Уверенная работа с Linux сервером из командной строки, понимание основ управления дисками и сетями.
