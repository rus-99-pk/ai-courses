# Практический курс по CI/CD: от новичка до автоматизатора

Добро пожаловать в практический курс по CI/CD! Здесь мы на реальных примерах разберем, как автоматизировать проверку, сборку и доставку вашего кода с помощью **GitLab CI** и **GitHub Actions**.

Этот курс построен по принципу "решаем конкретную задачу". Каждая тема — это отдельный шаг в построении полноценного конвейера (pipeline) для вашего проекта.

## Структура курса

Курс разбит на несколько тем, каждая из которых находится в отдельном `.md` файле. Рекомендуется проходить их последовательно.

*   **[Тема 0: Введение в CI/CD](00-intro.md)**
    *   Что такое CI/CD и зачем это нужно?
    *   Основные концепции: pipeline, job, stage, runner/agent.
    *   Сравнение GitLab CI и GitHub Actions.

*   **[Тема 1: "Hello, World!" - Ваш первый Pipeline](01-hello-world.md)**
    *   **Задача:** Запустить простейшую автоматизацию при коммите в репозиторий.
    *   Создаем первый `.gitlab-ci.yml` и `.github/workflows/main.yml`.
    *   Разбираем базовый синтаксис.

*   **[Тема 2: Линтинг и Тестирование](02-linting-and-testing.md)**
    *   **Задача:** Автоматически проверять качество кода и запускать тесты.
    *   Настраиваем запуск линтера (например, `flake8` для Python) и тестов (`pytest`).
    *   Работа со статусами завершения задач (успех/провал).

*   **[Тема 3: Сборка артефактов](03-building-artifacts.md)**
    *   **Задача:** Собирать результат работы pipeline (например, бинарный файл, архив с сайтом или Docker-образ).
    *   Создание и сохранение артефактов в GitLab CI.
    *   Загрузка и скачивание артефактов в GitHub Actions.
    *   Пример сборки Docker-образа.

*   **[Тема 4: Окружения и Секреты](04-environments-and-secrets.md)**
    *   **Задача:** Безопасно хранить и использовать чувствительные данные (токены, пароли) в CI/CD.
    *   Настройка переменных окружения (Variables) в GitLab.
    *   Использование секретов (Secrets) в GitHub.
    *   Разделение конфигурации для `staging` и `production`.

*   **[Тема 5: Непрерывная доставка (Continuous Deployment)](05-deployment.md)**
    *   **Задача:** Автоматически разворачивать приложение на сервере.
    *   **Пример 1:** Деплой статического сайта на GitLab/GitHub Pages.
    *   **Пример 2:** Деплой на удаленный сервер по SSH.

*   **[Тема 6: Оптимизация с помощью кэширования](06-caching.md)**
    *   **Задача:** Ускорить выполнение pipeline за счет кэширования зависимостей (npm-пакеты, pip-библиотеки).
    *   Настройка `cache` в GitLab CI.
    *   Использование `actions/cache` в GitHub Actions.

*   **[Тема 7: Ручные триггеры и утверждения](07-manual-triggers-and-approvals.md)**
    *   **Задача:** Запускать деплой на production только после ручного подтверждения.
    *   Настройка `when: manual` в GitLab CI.
    *   Использование `workflow_dispatch` и `environments` с `reviewers` в GitHub Actions.

*   **[Тема 8: Матричные сборки](08-matrix-builds.md)**
    *   **Задача:** Запускать тесты одновременно на разных версиях языка или ОС.
    *   Использование `matrix` в GitLab CI и GitHub Actions для параллельного тестирования.

*   **[Тема 9: Заключение и дальнейшие шаги](09-conclusion.md)**
    *   Подведение итогов.
    *   Куда двигаться дальше: безопасность (SAST/DAST), инфраструктура как код (IaC), мониторинг.

## Необходимые условия

*   Базовое понимание `git`.
*   Аккаунт на [GitLab.com](https://gitlab.com) и [GitHub.com](https://github.com).
*   Установленный `git` на вашем компьютере.
