# Тема 1: "Hello, World!" - Ваш первый Pipeline

## Какую проблему решаем?

Мы хотим, чтобы при каждом коммите в наш репозиторий автоматически запускалась простейшая задача, которая просто выводит приветственное сообщение. Это покажет, что система CI/CD работает и "видит" наши изменения.

### Подготовка

1.  Создайте новый пустой репозиторий на GitLab и/или GitHub.
2.  Склонируйте его себе на компьютер.

---

### GitLab CI

1.  В корне репозитория создайте файл `.gitlab-ci.yml`.
2.  Добавьте в него следующий код:

```yml
# .gitlab-ci.yml

# Определяем этапы. Пока у нас только один.
stages:
  - build

# Определяем задачу (job)
hello_world_job:
  stage: build  # Привязываем задачу к этапу
  script:
    - echo "Hello, World from GitLab CI!"
    - echo "This job is running in the build stage."
```

**Разбор команд:**
*   `stages`: Список всех этапов вашего pipeline. Выполнение идет последовательно.
*   `hello_world_job`: Произвольное имя вашей задачи (job).
*   `stage: build`: Указывает, что эта задача принадлежит этапу `build`.
*   `script`: Самая важная часть. Здесь перечислены команды, которые будут выполнены на раннере.

**Что делать:**
1.  Закоммитьте и отправьте (`git push`) этот файл в ваш GitLab репозиторий.
2.  Перейдите в раздел `CI/CD -> Pipelines` в вашем проекте на GitLab. Вы увидите запущенный pipeline!

---

### GitHub Actions

1.  В корне репозитория создайте директорию `.github`, а внутри нее — директорию `workflows`.
2.  Внутри `.github/workflows/` создайте файл `main.yml`.
3.  Добавьте в него следующий код:

```yml
# .github/workflows/main.yml

# Название нашего workflow
name: Hello World Workflow

# Триггер: запускать на каждый push в ветку main
on:
  push:
    branches: [ "main" ]

# Задачи (jobs), которые нужно выполнить
jobs:
  # Название задачи
  hello_world_job:
    # На какой виртуальной машине запустить
    runs-on: ubuntu-latest
    # Шаги, которые нужно выполнить в рамках задачи
    steps:
      - name: Say hello
        run: |
          echo "Hello, World from GitHub Actions!"
          echo "This job is running on a ubuntu runner."
```

**Разбор команд:**
*   `name`: Имя всего workflow, которое будет отображаться в интерфейсе GitHub.
*   `on: push: branches: [ "main" ]`: Триггер. Этот workflow будет запускаться при каждом `push` в ветку `main`.
*   `jobs`: Секция, описывающая все задачи.
*   `hello_world_job`: Имя задачи.
*   `runs-on: ubuntu-latest`: Указывает, что задача должна выполняться на виртуальной машине с последней версией Ubuntu.
*   `steps`: Список шагов внутри задачи.
*   `run`: Выполняет команду в оболочке. Многострочные команды можно писать с помощью `|`.

**Что делать:**
1.  Закоммитьте и отправьте (`git push`) эти файлы в ваш GitHub репозиторий.
2.  Перейдите во вкладку `Actions` в вашем репозитории. Вы увидите запущенный workflow!
```
... и так далее для каждого файла.
