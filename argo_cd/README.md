# Курс по ArgoCD: от основ до продвинутых техник

Добро пожаловать в курс по ArgoCD! Этот курс предназначен для DevOps-инженеров, разработчиков и всех, кто хочет внедрить GitOps-подход для управления своими Kubernetes-кластерами.

Мы пройдем путь от теоретических основ GitOps до практического развертывания сложных приложений, управления секретами и интеграции с CI/CD.

## Структура курса

Каждый файл представляет собой отдельный урок. Рекомендуется проходить их последовательно.

*   **[00 - Введение в GitOps и ArgoCD](00_Introduction_to_GitOps_and_ArgoCD.md)**
    *   Что такое GitOps и почему это важно.
    *   Роль ArgoCD в экосистеме GitOps.
*   **[01 - Установка и настройка](01_Installation.md)**
    *   Установка ArgoCD в ваш Kubernetes кластер.
    *   Доступ к UI и CLI.
*   **[02 - Развертывание первого приложения](02_First_Application.md)**
    *   Создание приложения через UI и CLI.
    *   Синхронизация состояния кластера с Git-репозиторием.
*   **[03 - Ключевые концепции](03_Core_Concepts.md)**
    *   Политики синхронизации (Sync Policies).
    *   Статусы здоровья (Health Status).
    *   Проекты (Projects) для изоляции и RBAC.
    *   Волны синхронизации (Sync Waves).
*   **[04 - ApplicationSet: Управление в масштабе](04_ApplicationSet.md)**
    *   Решение проблемы "копипасты" для множества приложений.
    *   Использование генераторов для автоматического создания `Application`.
*   **[05 - Управление секретами](05_Secrets_Management.md)**
    *   Почему нельзя хранить секреты в Git в открытом виде.
    *   Практические подходы: Sealed Secrets и External Secrets Operator.
*   **[06 - Интеграция с CI/CD](06_CI_CD_Integration.md)**
    *   Как связать ваш CI-пайплайн (сборку образа) с CD (развертыванием через ArgoCD).
    *   Паттерны обновления версий в Git.
*   **[07 - Уведомления](07_Notifications.md)**
    *   Настройка уведомлений о статусе приложений в Slack, Email и др.
*   **[08 - Лучшие практики](08_Best_Practices.md)**
    *   Структурирование Git-репозиториев.
    *   Использование хуков (Resource Hooks).
    *   Советы по безопасности и производительности.

## Пререквизиты

*   Базовое понимание Kubernetes (Pods, Deployments, Services).
*   Установленный `kubectl` и доступ к Kubernetes-кластеру (например, minikube, kind, Docker Desktop).
*   Аккаунт на GitHub (или другом Git-провайдере).
*   Установленный `git` на вашей локальной машине.
