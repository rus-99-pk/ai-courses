*   **Урок 8: Микросервисы, Балансировка и Кеширование**
    *   **Цель:** Понять принципы микросервисной архитектуры, научиться управлять группой контейнеров локально и обеспечивать доступность/производительность с помощью балансировки.
    *   **Ключевые Темы:**
        *   Архитектурные стили: Монолит vs Микросервисы (преимущества и недостатки).
        *   Введение в управление микросервисными приложениями.
        *   Docker Compose: Описание мульти-контейнерных приложений (`docker-compose.yml`), сети, вольюмы.
        *   Балансировка нагрузки: Зачем нужна, алгоритмы (Round Robin, Least Connection), Reverse Proxy.
        *   Nginx (или Traefik/HAProxy): Установка, настройка как Reverse Proxy и Load Balancer.
        *   Кеширование: Зачем нужно, типы кешей (браузерный, серверный, CDN), Nginx как кеширующий прокси.
        *   Стратегии развертывания (углубленно): Blue/Green, Canary в контексте балансировщиков.
    *   **Практические Задачи (Hands-on Labs):**
        1.  **Docker Compose App:** Если ваше приложение монолит, попробуйте разделить его на 2-3 простых сервиса (например, UI, Backend API, Worker). Или взять готовый пример микросервисного приложения. Описать его структуру с помощью `docker-compose.yml`. Запустить все сервисы одной командой.
        2.  **Nginx Setup:** Развернуть Nginx на отдельной VM (или как контейнер).
        3.  **Nginx Reverse Proxy:** Настроить Nginx как Reverse Proxy для вашего приложения (если оно запущено как монолитный контейнер или группа контейнеров).
        4.  **Nginx Load Balancer:** Если у вас есть несколько экземпляров приложения (запущенных как отдельные контейнеры или на разных портах), настроить Nginx как Load Balancer, распределяющий трафик между ними. Попробовать разные алгоритмы балансировки.
        5.  **Nginx Caching:** Настроить Nginx для кеширования ответов вашего приложения. Проверить работу кеша.
        6.  **Scale with Docker Compose:** Попробовать масштабировать сервис с помощью `docker-compose up --scale service_name=N` и увидеть, как балансировщик распределяет нагрузку.
    *   **Результат:** Умение описывать и запускать мульти-контейнерные приложения с Docker Compose, использовать Nginx для балансировки нагрузки и кеширования для повышения доступности и производительности.
