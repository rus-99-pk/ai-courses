*   **Урок 11: Итоговый Проект (3 недели)**
    *   **Цель:** Применить все полученные знания на практике, построив с нуля (или почти с нуля) полный DevOps конвейер для нового приложения или расширив существующий проект, добавив в него новые аспекты (например, новую БД, микросервис, более сложную инфраструктуру).
    *   **Задача Проекта:**
        *   Выбрать (или получить) простое веб-приложение (желательно с зависимостью от БД и каким-то внешним сервисом/хранилищем).
        *   Создать репозиторий в Git (Gitea/GitLab).
        *   Настроить CI pipeline (Jenkinsfile или .gitlab-ci.yml) для:
            *   Сборки приложения (например, Maven, Gradle, npm, pip).
            *   Запуска тестов (Unit, Integration).
            *   Анализа качества и безопасности кода (SonarQube).
            *   Сборки Docker образа приложения.
            *   Публикации Docker образа в Container Registry (Nexus, GitLab Registry).
            *   Публикации Maven/других артефактов в Nexus.
        *   Описать инфраструктуру для приложения с помощью Terraform (как минимум, K8s кластер - Minikube/Kind для простоты, или облачный Managed K8s).
        *   Описать конфигурацию БД (PostgreSQL/MongoDB) с помощью Terraform/Ansible.
        *   Настроить DBOps: использовать Flyway/Liquibase для миграций БД, интегрировать их в pipeline.
        *   Настроить хранение секретов приложения в Vault и обеспечить их доступность для приложения в K8s.
        *   Настроить деплой приложения в K8s:
            *   Использовать Helm Chart для упаковки приложения.
            *   Настроить GitOps с помощью Argo CD/Flux для автоматического деплоя Helm Chart'а из Git репозитория при изменениях.
            *   Настроить Service и Ingress для доступа к приложению.
            *   Продумать стратегию деплоя (Rolling Update по умолчанию, но можно обсудить Blue/Green или Canary).
        *   Настроить стек мониторинга и логирования (Prometheus, Grafana, Loki, Alertmanager) для:
            *   Сбора метрик с приложения.
            *   Сбора логов приложения.
            *   Визуализации метрик и логов на дашбордах Grafana.
            *   Настройки базовых алертов.
        *   Описать процесс отката на предыдущую версию.
        *   Написать краткую документацию (например, в форме README) по проекту, описывающую архитектуру, пайплайн, инструкции по развертыванию.
    *   **Процесс:** Работа над проектом итеративно. Каждую неделю ставить себе цели (например, 1 неделя - CI/CD до публикации образа/артефактов, 2 неделя - IaC, DB, Secrets, 3 неделя - K8s, GitOps, Monitoring).
    *   **Результат:** Полностью функциональный DevOps конвейер, демонстрирующий умение работать со всеми ключевыми инструментами и принципами курса. Это будет отличное портфолио и основа для собеседований на позиции Middle+/Senior.
