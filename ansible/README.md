# Курс: Управление конфигурацией с Ansible

Добро пожаловать в практический курс по Ansible! Здесь вы пройдете путь от основ до уверенного использования Ansible для автоматизации задач системного администрирования.

Курс построен по принципу "проблема -> решение". Мы будем разбирать типичные задачи и показывать, как Ansible помогает их решать эффективно и идемпотентно.

## Как проходить курс?

Последовательно изучайте темы, читайте `.md` файлы и, самое главное, **выполняйте все примеры команд на практике**. Для этого вам понадобится:
*   **Control Node**: Ваш рабочий компьютер (Linux/macOS) или виртуальная машина с Linux, где будет установлен Ansible.
*   **Managed Node(s)**: Одна или несколько виртуальных машин (например, Ubuntu/CentOS), к которым у вас есть SSH-доступ с правами `sudo`.
